# 📊 AtliQ Hardware Business Analytics Project

A data analytics project aimed at transforming AtliqQ Hardware’s decision-making by moving from Excel-based reporting to a modern, interactive Power BI dashboard. The goal was to uncover insights from historical data to address past losses and improve future performance in Latin America.

## 🚀 Project Highlights

### 🏠 Home Page
- Centralized navigation hub for seamless access to various report sections.

### 💰 Finance View
- Displays core financial KPIs with interactive visuals and filterable parameters.

### 📈 Sales View
- Presents sales insights using scatter plots, customer/product performance metrics, and donut charts.

### 📢 Marketing View
- Analyzes marketing segment performance with waterfall charts and dynamic tables.

### 🚚 Supply Chain View
- Tracks key supply chain metrics with trend analysis and detailed breakdowns.

### 👨🏻‍💼 Executive View
- Executive summary page showcasing top-level metrics, revenue trends, and performance indicators.

## 🧠 Power BI Skills Practiced

- Data modeling and relationship management  
- Calculated columns & measures with DAX  
- Creating dynamic visuals using bookmarks & buttons  
- Conditional formatting with icons/backgrounds  
- KPI indicators and dynamic titles based on filters  
- Creating a custom date table with M language  
- Data validation and performance optimization  
- Publishing to Power BI Service  
- Setting up personal gateway for auto-refresh  
- Workspace collaboration and access permissions

## 📌 Problem Statement

AtliqQ Hardware suffered losses in Latin America due to inefficient, Excel-based analytics. This project was launched to enhance reporting and analysis capabilities using Power BI and structured data pipelines, enabling better decision-making backed by interactive dashboards and KPIs.
